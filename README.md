## Oceana - Discord-бот с одной большой игрой, где всё происходит внутри изображений.

- Привет! Я, @vejoy_, ищу тех, кто готов помочь в совместной разработке дискорд бота на языке Javascript.
- Это бот с одной большой игрой, где игроку предстоит управлять своим кораблём в бесконечном 2д мире с видом сверху. На пути игрока предстоит ловля рыбы, поиск сокровищ, прокачка корабля на острове а так-же опасные погодные условия, акулы и враги.
- Этот репозиторий будет открыт вплоть до момента, когда бот будет находиться в "играбельном" состоянии. Все кто проявил помощь - будут приглашены когда репозиторий станет приватным.

### Требования для запуска
1. Наличие установленого [bun](https://bun.sh/) **ЛИБО** [Docker](https://docs.docker.com/desktop/)
2. Наличие базы данных MongoDB, к которой вы сможете подключиться

## 1. Рекомендуемый запуск. Через Docker. На любой операционной системе.
1. Клонируете репозиторий, ```git clone https://github.com/Ve-Jo/oceana.git```
2. Устанавливаете Docker, следуя инструкциям на [офф. сайте Docker](https://docs.docker.com/engine/install/) 
3. Соберите проект, прописав в терминале в папке проекта: ```docker build . -t oceana```
4. Дождитесь окончания всех этапов.
5. Запустите бота через ```docker run oceana```
6. При необходимости закрыть его, делайте ```CRTL + C```. Вы можете так-же смотреть что у вас запущено через ```docker stats```.

## 2. Рекомендуемый запуск. Через bun на WSL (Windows Subsystem Linux) / Linux.
1. Клонируете репозиторий, ```git clone https://github.com/Ve-Jo/oceana.git```
2. Устанавливаете bun ```curl -fsSL https://bun.sh/install | bash```
3. Устанавливаете библиотеки, ```bun i```
4. Скачиваете браузер, который бот будет использовать, ```bunx playwright install Chromium``` (либо Firefox, Webkit)
5. Создаёте файл ```.env```, в котором заполните все данные в том же виде, что и у ```.env.example``` (Всуньте токен вашего дискорд бота, его айди и ссылку на вашу монгу)
6. Запускаете через ```bun .``` :)

* Важно знать. Если вы запускаете бота через WSL, желательно перенести все его файлы внутрь WSL-я что-бы не было проблем и бот запускался быстро. 
Укажите `\\wsl$` в строку поиска папки в вашем проводнике, и вы попадёте туда.

## 3. НЕ РЕКОМЕНДУЕМЫЙ запуск. Через experimental билд bun-а для Windows.
1. Клонируете репозиторий, ```git clone https://github.com/Ve-Jo/oceana.git```
2. Устанавливайте bun через команду внутри powershell ```powershell -c "irm bun.sh/install.ps1|iex"```
3. В файле ```index.js``` модуль "Browser" коментируйте, что-бы получилось вот так:
```js
...
	"Mongoose",
	/*"Browser",*/ <<<
	"ProcessUsage",
	"Caching",
].map(async (file) => {
...
```
4. Запускайте бота через `bun .`. Учтите, что браузер работать не будет. Только рендеринг через canvas.

## Можно ли запустить его через Node?
- Нет. Вы можете дождаться официального релиза bun для Windows. Либо скачивать WSL и устанавливать bun на нём. Либо запускать бота через Docker.
