## Oceana - Discord-бот с одной большой игрой, где всё происходит внутри изображений.

- Привет! Я, @vejoy_, ищу тех, кто готов помочь в совместной разработке дискорд бота на языке Javascript с внедрением изображений через веб-страницы (HTML/CSS).
- Это бот с одной большой игрой, где игроку предстоит управлять своим кораблём в бесконечном 2д мире с видом сверху. На пути игрока предстоит ловля рыбы, поиск сокровищ, прокачка корабля на острове а так-же опасные погодные условия, акулы и враги.
- Этот репозиторий будет открыт вплоть до момента, когда бот будет находиться в "играбельном" состоянии. Все кто проявил помощь - будут приглашены когда репозиторий станет приватным.

## Что нужно для запуска бота у себя?
1. Наличие установленого [bun](https://bun.sh/)
(Имейте в виду, если вы с Windows - вам придётся запускать бота через WSL, предварительно установив bun туда и перетащив файлы бота в диск вашего WSL. Либо, можете поэксперементировать и запустить через Docker файл, который есть в проекте)
2. Наличие базы данных MongoDB, к которой вы сможете подключиться (Могу предоставить, если отпишитесь мне лично)
3. Советуем расширения для VSCode: "Live Preview" (Для того, что-бы смотреть HTML страницы прямо в редакторе), "Prettier" (Так-же настройте его, что-бы он использовал имеющийся в проекте .prettierrc)

## Как запустить?
1. Клонируете репозиторий, ```git clone https://github.com/Ve-Jo/oceana.git```
2. Устанавливаете библиотеки, ```bun i```
3. Скачиваете браузер, который бот будет использовать, ```bunx playwright install Chromium``` (либо Firefox, Webkit)
4. Создаёте файл ```.env```, в котором заполните все данные в том же виде, что и у ```.env.example``` (Всуньте токен вашего дискорд бота, его айди и ссылку на вашу монгу)
5. Запускаете через ```bun .``` :)
